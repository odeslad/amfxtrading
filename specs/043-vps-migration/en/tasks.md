# 043 — VPS migration · Tasks

Each task is one conventional commit. Tasks that are operations on the servers change no source file: their commit is the `verification.md` entry with the evidence (`docs(specs):`). Tasks of different layers never share a commit. The old system stays in production at `v2.amfxtrading.com` until task 13. Order: preparation (1–7) → publication under the new names (8–12) → switch (13) → documentation (14) → validation and observation (15) → closure (16).
